# Envision the Heavens™ Releases

This repository is the public binary distribution home for Envision the Heavens™ (Envision
for short), the PMC-Eight™ telescope-mount app formerly called ExploreStars Envision.

It is intentionally release-only. Source code is not published here.

## Downloads

Use the latest GitHub Release for current customer downloads:

- Android APK
- Windows ZIP
- PWA Server ZIP for Apple devices and browser-equipped devices
- User Manual (HTML)
- SHA256 checksum file
