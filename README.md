# ExploreStars Envision Releases

This repository is the public binary distribution home for ExploreStars Envision.

It is intentionally release-only. Source code is not published here.

## Downloads

Use the latest GitHub Release for current customer downloads:

- Android APK
- Windows ZIP
- PWA Server ZIP for Apple devices and browser-equipped devices
- SHA256 checksum file

The `release-assets/latest` folder mirrors the current release assets for local staging.
